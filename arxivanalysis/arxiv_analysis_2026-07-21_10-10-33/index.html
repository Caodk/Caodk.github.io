1. 基于优化区域分解方法的混合维Biot问题#

Hybrid-Dimensional Biot Problem with an Optimization Based Domain Decomposition Approach

作者: Francesca Marcon, Stefano Scialò

类别: math.NA

发布日期: 2026-07-20

arXiv ID: 2607.17885v1

摘要翻译: 本文提出了一种数值方法，用于求解裂缝性多孔介质中的流固耦合问题，该介质被表示为混合维区域。在该公式中，允许三维网格的单元任意穿过裂缝。通过在三维网格上使用扩展有限元方法（XFEM），位移在裂缝处不连续。力学问题被表述为一个鞍点问题，其中使用拉格朗日乘子来强制裂缝处的位移连续性。所得的拉格朗日乘子表示作用在裂缝表面上的应力场。类似地，通过在不协调网格上使用XFEM公式，允许压力场在裂缝处不连续，并使用专门为混合维问题设计的基于优化的区域分解策略来计算压力场。采用固定应力分裂格式解耦流动和力学子问题，而在每个固定应力迭代中使用共轭梯度（CG）方法求解混合维压力问题。固定应力格式与CG求解器的组合对于这类问题证明是高效的。

1. 研究对象和背景#

本文研究多孔介质中流体流动与固体变形的耦合问题, 其背景源于地热能开发, 二氧化碳地质封存, 地下水资源管理及地震活动分析等应用. 研究的几何对象是一个三维多孔基岩域 D, 其中包含一个或多个平面裂缝 F^j (j=1,…,#F), 裂缝被建模为二维流形(离散裂缝-基质模型, DFM). 记 ˚D = D \ ∪j F^j 为不含裂缝的矩阵域. 在裂缝表面, 流场与力学场均可能发生间断. 物理上, 采用线性 Biot 模型描述饱和多孔介质中孔隙压力与骨架变形的耦合: 在 ˚D 上满足\n\n$$\frac{\partial}{\partial t}\left(\frac{1}{M}p_D + \alpha \nabla\cdot \mathbf{u}\right) - \nabla\cdot(K_D \nabla p_D) = g, \qquad (x,t)\in \mathring{D}\times(0,T], \tag{1}$$\n$$\alpha\nabla p_D - \nabla\cdot \boldsymbol{\sigma}(\mathbf{u}) = 0, \qquad (x,t)\in \mathring{D}\times(0,T], \tag{4}$$\n\n其中 p_D 为孔隙压力, u 为位移, M 为 Biot 模量, α 为 Biot-Willis 系数, K_D = k_D/μ 为基质渗透率与流体粘度之比, g 为源汇项. 应力-应变本构为线弹性: σ(u) = C ε(u), C 为四阶弹性张量, ε(u) = (∇u + ∇uᵀ)/2. 在每个裂缝 F^j 上, 二维流动满足 Darcy 定律:\n\n$$-\nabla\cdot(K_{F^j}\nabla p_{F^j}) + K_D\nabla p_{D,+}^j\cdot\mathbf{n}_+^j + K_D\nabla p_{D,-}^j\cdot\mathbf{n}_-^j = 0, \qquad (x,t)\in F^j\times(0,T], \tag{2}$$\n\n以及矩阵-裂缝窜流条件:\n\n$$K_D\nabla p_{D,\pm}^j\cdot\mathbf{n}_\pm^j = -\eta^j(p_{D,\pm}^j - p_{F^j}), \qquad (x,t)\in \omega_\pm^j\times(0,T], \tag{3}$$\n\n这里 η^j = k\perp^j/μ 为裂缝法向传导系数, K_{F^j} = k_\parallel^j/μ 为裂缝切向传导系数, p_{D,\pm}^j 分别表示压力在裂缝两侧的迹. 在力学上, 裂缝两侧应力连续条件由 Lagrange 乘子 Λ^j 表示:\n\n

$$\big(\boldsymbol{\sigma}_\pm^j(\mathbf{u}) - \alpha p_{D,\pm}^j\mathbf{I}\big)\cdot\mathbf{n}_\pm^j = \Lambda^j - \alpha p_{F^j}\mathbf{n}_\pm^j, \qquad (x,t)\in \omega_\pm^j\times(0,T], \tag{5}$$

\n\n且位移连续性约束:\n

$$\mathbf{u}_+^j = \mathbf{u}_-^j \quad \text{在} F^j\times(0,T]. \tag{6}$$

\n\n边界条件取齐次 Dirichlet/Neumann 条件, 初始条件为静止.\n\n尽管 Biot 方程的数值求解已有广泛研究, 但在含裂缝的混合维情形下, 传统方法通常要求计算网格与裂缝位置匹配(即网格面严格贴合裂缝), 这给复杂裂缝网络(如大量相交裂缝, 非平面裂缝)的网格生成带来巨大困难. 文献中已有的工作, 如[9]使用混合有限元-有限体积法, [7]从降维 Brinkman-Biot 模型出发, [3]结合接触力学条件, [6]使用完全匹配网格并分析固定应力参数敏感性, 均要求匹配网格. 为突破这一限制, 本文在非匹配网格上发展数值方法. 其基本思路是: 利用扩展有限元(XFEM)引入 Heaviside 或 bubble 型富集函数捕捉跨越裂缝的间断; 并通过优化基区域分解策略将全局问题解耦为矩阵三维问题和各个裂缝二维问题, 从而允许对矩阵和裂缝独立划分网格. 此外, 耦合问题通过固定应力分裂格式(见[13])将流动与力学迭代解耦, 每一时间步内交替求解压力方程和力学方程. 本文的目标正是将上述思想系统性地推广到混合维 Biot 问题, 给出完整的空间-时间离散、分裂格式、收敛性证明以及数值验证. 尤其值得指出的是, 文中给出了固定应力分裂在该非匹配混合维离散框架下的严格收敛性分析, 这是以往文献中未曾涉及的.\n\n本文试图填补的空白可概括为: 在无需网格匹配的条件下, 构造并分析一套求解含有多条裂缝的三维-二维 Biot 方程的高效数值方案, 并证明所采用的固定应力迭代的线性收敛性. 该工作为复杂裂缝性多孔介质中的流固耦合模拟提供了兼具灵活性和理论保证的计算框架.

2. 主要定理或主要结果#

本文的核心理论结果是关于固定应力分裂格式在混合维非匹配离散下的收敛性证明. 在假设 A.1 (α, λ, μ > 0, 1/M, K_D ≥ 0) 和 A.2 (对每条裂缝 η^j > 0, K_{F^j} ≥ 0) 之下, 作者定义了第 k 时间步内固定应力迭代的误差量(见(39)): e^{k,i}{p_D} = (p_D)^{k,i} - (p_D)^k, e^{k,i}{p_F^j} = (p_F^j)^{k,i} - (p_F^j)^k, e^{k,i}u = u^{k,i} - u^k, e^{k,i}Λ = (Λ^j)^{k,i} - (Λ^j)^k, 其中 (·)^k 表示精确的时空离散解(由 Problem 4 给出), (·)^{k,i} 表示第 i 次迭代解. 通过误差方程(43)–(46)及细致的能量估计, 定理 1 得到以下三个不等式:\n\n1. 力学误差受压力误差控制:\n$$2\mu \|\epsilon(e^{k,i}_u)\|_{0,\mathring{D}}^2 + \lambda \|\nabla\cdot e^{k,i}_u\|_{0,\mathring{D}}^2 \le \frac{\alpha^2}{K_{\text{dr}}} \|e^{k,i}_{p_D}\|_{0,\mathring{D}}^2. \tag{40}$$\n\n2. 裂缝压力误差受其两侧压力跳跃控制:\n$$K_{F^j} \|\nabla e^{k,i}_{p_{F^j}}\|_{0,\omega^j}^2 + 2\eta^j \|e^{k,i}_{p_{F^j}}\|_{0,\omega^j} \le \frac{\eta^j}{\delta_F} \|(e^{k,i}_{p_D})^j_\pm\|_{0,\omega^j}^2, \quad \forall j, \tag{41}$$\n其中 δ_F ≤ 2, |(e^{k,i}{p_D})^j\pm|{0,\omega^j}^2 = \int{\omega^j} ([(e^{k,i}{p_D})+^j]^2 + [(e^{k,i}{p_D})-^j]^2).\n\n3. 压力误差自身满足压缩性(即误差每次迭代按常数因子衰减):\n

$$\left(\frac{1}{M} + \frac{\alpha^2}{2K_{\text{dr}}} + \frac{\Delta t\, K_D}{C_P}\right) \|e^{k,i}_{p_D}\|_{0,\mathring{D}}^2 \le \frac{\alpha^2}{2K_{\text{dr}}} \|e^{k,i-1}_{p_D}\|_{0,\mathring{D}}^2. \tag{42}$$

\n这里 K_{\text{dr}} = λ + (2/3)μ 为排水体积模量, C_P 为 Poincaré 常数. 由(42)立即得到压缩因子\n

$$\rho = \frac{\alpha^2/(2K_{\text{dr}})}{1/M + \alpha^2/(2K_{\text{dr}}) + \Delta t\, K_D/C_P} < 1,$$

\n从而保证迭代收敛.\n\n在数值实现层面, 3D 压力空间 V^{f,D}_h 通过 XFEM 构造(22): 标准线性 Lagrange 元加上两类富集函数——对完全穿越域 D 的裂缝采用符号函数 H^j, 对终止于域内的裂缝采用 bubble 函数 E^j 与 H^j 的乘积, 并作平移调整以保证分片线性性质. 力学位移空间 V^m_h 按同样方式构造. 每条裂缝上的标量空间(压力和 Lagrange 乘子)采用标准线性有限元.\n\n进一步的数值实验部分(第 6 节, 原文未提供细节)显示, 固定应力迭代与共轭梯度法求解流动子问题的组合对于此类问题非常高效. 但具体的收敛阶, 参数影响和计算时间等定量结果需要查阅原文第 6 节, 此处从已提供文本无法明确给出.

3. 研究方法、关键技术和核心工具#

本文的数值方案建立在三个核心技术的有机结合之上: 扩展有限元(XFEM)的间断表示, 固定应力算子分裂, 以及优化基区域分解. 其技术上的主要障碍在于: 如何在不要求网格匹配裂缝的条件下, 既精确捕捉压力和位移在裂缝两侧的跳跃, 又保持混合维耦合的物理一致性, 同时还要在迭代解耦的过程中保证整体收敛. 作者围绕这些障碍展开分析框架.\n\n1. XFEM 间断逼近与富集函数构造.\n非匹配网格上处理裂缝的关键是引入能够表示跨裂缝间断的插值基函数, 且不增加全局自由度总数. 文中对 3D 压力 p_D 和位移 u 均采用 XFEM 空间(22). 定义 P_1( T_D ) 为 3D 网格 T_D 上满足齐次 Dirichlet 条件的标准线性 Lagrangian 有限元空间. 对于每条裂缝 F^j, 作者区分两种情况:\n - 若 F^j 完全穿越计算域, 则使用 Heaviside 函数 H^j( x ) = sign( n_{F^j}·(x - x_0) ) 来构造间断, 相应富集基函数为 H^j_k = ϕ_k(x)(H^j(x) - H^j(x_k)).\n - 若 F^j 终止在域内, 直接使用 H^j 会导致域外的虚假间断, 因此需引入一个在裂缝边界上光滑归零的 bubble 函数 E^j. 其定义基于裂缝内部边缘: 在裂缝局部坐标系下, 对每条内部边缘所在的直线方程 ε_i^j 取乘积, 并通过简单缩放保证在裂缝重心处取值为 1. 最终富集函数为 H^j(x)E^j(x), 并经平移调整为 E^j_k = ϕ_k(x)( H^j(x)E^j(x) - H^j(x_k)E^j(x_k) ). 作者特别指出参数 p 控制函数光滑度, 数值实验中取 p = 1/2. 这一构造保证了在裂缝内部单元上函数具有所需的间断性, 而在远离裂缝的区域其对标准有限元空间无扰动(因为当 x 不在裂缝影响区时 E^j(x)=0). 这种技术使得网格完全不需贴合裂缝, 大大降低了网格生成难度.\n\n2. 固定应力分裂及其收敛性证明.\n耦合系统(29)-(32)是全离散(向后 Euler 时间步 + 空间离散)后所得. 为了避免整体求解的巨大计算量, 采用固定应力迭代: 在第 i 次迭代, 先以已知的位移 u^{k,i-1} 解压力方程, 再以所得压力解力学方程, 并反复迭代至满足容差. 为恢复迭代收敛性, 需要在压力方程中增加稳定项 L(p_D^{k,i} - p_D^{k,i-1}), 其中 L 取物理启发的值 L = α^2/K_{\text{dr}}, 该选择等价于在整个迭代过程中“固定”体积应力平均量(见(33)). 收敛性证明是本文的理论核心. 证明框架如下:\n - 首先写出线性误差满足的方程(43)-(46).\n - 从力学误差方程(45)取试函数 v_h = e^{k,i}u, 并利用约束(47)得到(48). 再结合 Young 不等式和不等式(34), 导出力学能量与压力误差的关系(40).\n - 由裂缝压力误差方程(44)取 q{F^j} = e^{k,i}{p{F^j}}, 同样应用 Young 不等式得到(41).\n - 组合压力误差方程(43)与力学、裂缝误差的能量恒等式, 关键处理项为 ∫ α e^{k,i}{p_D} ∇·(e^{k,i}u - e^{k,i-1}u). 利用(45)的差分形式(57)及 Cauchy-Schwarz 与(34), 将该位移差项用压力差控制(58). 将所有非正定项移至右端后, 反复使用 Young 不等式合并同类项, 最终消去位移和裂缝压力项, 得到仅含压力误差的压缩不等式(59)-(60), 即(42). 整个过程需精细选取 Young 系数 δ_U ∈ [1,2], δ_P ∈ [1,2], δ_F ≤ 2, 保证最后等式左端所有系数为正. 最终收敛因子为 α^2/(2K{\text{dr}}) 与 (1/M + α^2/(2K{\text{dr}}) + ∆t K_D/C_P) 之比, 显然小于 1. 该证明技巧拓展了经典固定应力收敛分析(如[19])至带多条裂缝与非匹配网格的情形, 且不依赖特定的有限元空间, 适用于较为一般的 XFEM 空间.\n\n3. 优化基区域分解用于流动子问题.\n在固定应力迭代的每一步, 需在给定 u^{k,i-1} 下求解三维-二维耦合 Darcy 流问题(35)-(36). 直接整体求解仍涉及三维矩阵与多条裂缝的耦合. 作者借鉴[16]的思想, 通过引入每条裂缝的额外界面变量 Ψ^j+, Ψ^j_-, Ψ^j_F, 将原耦合问题转化为一个等式约束下的最小化问题(61): 最小化 ∑j ( ‖(p_D)+^j - Ψ^j_+‖^2 + ‖(p_D)-^j - Ψ^j-‖^2 + ‖p_{F^j} - Ψ^j_F‖^2 ), 同时满足弱形式(35)-(36)将界面变量替换后得到的约束. 这种等价形式允许分别求解各子域: 固定界面变量时, 3D 压力 p_D 和每个 2D 压力 p_{F^j} 独立求解; 然后按梯度迭代更新界面变量. 算法最终等价于一个界面空间的共轭梯度(CG)迭代, 其中矩阵-向量乘积只需求解解耦的子域问题, 因此实现简单且可扩展. 当界面空间取为裂缝网格上的连续线性有限元或分片常数时, CG 被证明非常高效. 该策略彻底分离了几何复杂性, 使得三维网格生成与裂缝离散完全解耦.\n\n综合而言, 本文的技术创新不在于单一的公式推导, 而在于系统性地整合上述三部分, 为混合维 Biot 问题提供了一套可被严格分析的求解思路. 其中收敛性证明中的误差组合与 Young 不等式参数的选取尤其体现了作者对解耦过程中能量传递的精确控制.

4. 与之前工作的比较#

本文的工作与既有有限元法及区域分解文献在多个维度上可进行比较, 以下分若干方面具体说明.\n\n1. 与匹配网格方法的比较.\n已有的含裂缝多孔介质 Biot 问题数值方法大多要求计算网格与裂缝几何一致. 例如, [9] 研究 3D-2D 非线性 Biot 模型时采用混合有限元-有限体积离散, 并假定网格在裂缝处匹配; [3] 将 3D Biot 方程与接触力学条件结合, 同样使用匹配网格; [6] 在 3D 基质和 2D 裂缝上均采用标准有限元, 网格完全符合裂缝, 并针对固定应力稳定参数进行敏感性分析. 这些方法对于少量简单裂缝是成功的, 但当裂缝数量众多、相互交错或者非平面时, 生成匹配网格变得极其困难甚至无法实现. 本文提出的 XFEM + 优化域分解方法的核心优势正是在于完全摒弃了这一要求: 3D 网格 T_D 可以独立于裂缝生成(例如一个简单的背景四面体网格), 而裂缝网格 T_{F^j} 也各自独立, 仅需知道裂缝与背景网格的相交信息以构造 XFEM 富集函数. 这带来了极大的网格划分灵活性, 尤其在裂缝网络几何复杂时更为突出. 但是, 这种灵活性以引入额外界面变量和迭代求解子问题为代价: 优化域分解的每个 CG 迭代需要求解解耦的 3D 和 2D 问题, 这可能比直接整体求解增加了一次迭代的算术强度, 然而作者声称 CG 收敛足够快, 整体效率依然良好.\n\n2. 与之前 XFEM 及区域分解工作相比.\n将 XFEM 用于多孔介质流固耦合问题并非首次出现, 但本文的独特之处在于与优化域分解的结合以及给予固定应力迭代的收敛性分析. 在纯 Darcy 流方面, [16] 提出了优化基区域分解处理 3D-2D 耦合问题并允许多条裂缝, 本文正是将该思想从 Darcy 流推广到 Biot 孔力学, 并加入了力学方程的 XFEM 离散. 之前的 [10] 也曾用 Lagrange 乘子处理裂缝两侧位移连续性, 但网格是匹配的; 本文则在非匹配网格下同时处理力学与流动. 在 XFEM 相关文献中, 作者提到 [20] 的 bubble 函数构造方法, 但本文将其移植到混合维多裂缝的情形, 并针对完全穿越与内部终止两种裂缝类型分别处理, 这提升了方法的通用性. 此外, 在固定应力分裂的收敛分析方面, 早期工作 [13] 提出了该分裂, 并在均质弹性无裂缝情形证明了收敛; [19] 给出了更一般框架下的收敛证明; [5] 将其推广到弹塑性问题. 本文的收敛证明(定理 1)沿着 [5,19] 的路线, 但首次将其扩展到带有多条裂缝且采用 XFEM 和优化区域分解的混合维问题. 证明中额外需要处理裂缝界面项 e_{p_{F^j}} 和 e^{k,i}Λ, 以及 XFEM 间断带来的能量恒等式调整. 作者巧妙利用位移约束(47)消去 Lagrange 乘子项, 并通过 Young 不等式将裂缝能量吸收至右端, 最终仍得到只关于 p_D 的压缩估计. 这体现了该分析框架的强健壮性.\n\n3. 与固定应力分裂中常规稳定化比较.\n在经典固定应力分裂中, 稳定参数 L 的选择直接影响收敛速度. 文献中常见 L = α^2/K{\text{dr}} (物理驱动)和 L = α^2/(K_{\text{dr}} ^u) (基于不排水体积模量)等. 本文采用前者, 并在收敛证明中有效地利用了 (34) 式将体积应变能的系数与 K_{\text{dr}} 联系起来, 从而导出精确的压缩因子. 对于多裂缝情况, 该参数依然适用且与裂缝参数无关, 这简化了实际计算. 不过, 文中收敛因子与 Δt、K_D 和 Poincaré 常数 C_P 有关: 当 Δt 较大或 K_D 较大(高渗透性)时, 收敛变慢, 但与裂缝有关的量未出现在压缩因子中, 说明裂缝的存在并未恶化固定应力迭代的收敛性质, 这是本文的一个重要观察.\n\n4. 数值效果方面.\n由于本文的第 6 节未在提供内容中详细展现, 无法明确给出收敛阶和计算效率数据. 从摘要和结论性语句可知, 固定应力与 CG 的组合对于此类问题非常有效. 但具体与匹配网格方法的精度、效率定量对比, 以及 XFEM 富集函数中参数 p 的影响、界面离散的选择等细节, 需要读者查阅原文完整版本. 在此, 我们只能指出这些潜在的比较维度, 而无法给出确切的数值结论.\n\n总结而言, 本文相对于先前工作, 主要推进了三点: 将非匹配网格处理能力从 Darcy 推广到 Biot 方程; 给出了该框架下固定应力分裂的严格收敛性及其误差估计; 通过优化区域分解实现了压力问题的稳健且解耦的求解. 其假设条件(A.1, A.2)与经典 Biot 问题一致, 未附加额外的光滑性或参数限制, 适用范围与匹配网格方法相当. 局限性则在于: 当前分析限于线弹性、小变形和线性 Darcy 流, 且不考虑裂缝的接触和滑移(位移连续性条件(6)为强约束), 未涉及非线性渗流或材料非线性; 此外 XFEM 的实现相对复杂, 需要几何相交检测和特殊积分. 这些将是未来可能的扩展方向.
