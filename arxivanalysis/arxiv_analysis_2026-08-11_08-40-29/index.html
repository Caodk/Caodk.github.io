1. 研究对象和背景#

本文研究谐波波传播问题的非重叠区域分解法, 关注广义优化施瓦茨方法 (Generalized Optimized Schwarz Method, GOSM) 的粗空间预处理. 研究对象为如下 Helmholtz 型边值问题: 在有限 Lipschitz 区域 $\Omega \subset \mathbb{R}^d$ 上, 给定源项 $f \in L^2(\Omega)$, 频率参数 $\kappa > 0$ 和阻抗参数 $\kappa_* \ge 0$, 求 $u \in H^1(\Omega)$ 满足

$$\Delta u + \kappa^2 u = -f \quad \text{in } \Omega, \qquad \partial_n u - i \kappa_* u = 0 \quad \text{on } \partial\Omega.$$

该问题可写为变分形式: 求 $u \in H^1(\Omega)$ 使 $a(u,v) = \ell(v)$ 对所有 $v \in H^1(\Omega)$ 成立, 其中 $a(u,v) := \int_\Omega (\nabla u \cdot \nabla v - \kappa^2 u v)\,dx - i\kappa_* \int_{\partial\Omega} u v\,ds$, $\ell(v) = \int_\Omega f v\,dx$. 假定该问题唯一可解, 即 inf-sup 常数 $\alpha > 0$.

Després 算法是波传播区域分解的经典方法, 将计算域划分为互不重叠的子域, 在各子域独立求解后通过 Robin 迹的交换来耦合. 优化施瓦茨方法 (OSM) 通过调优 Robin 参数来加速收敛. GOSM 是 Després 算法的变体, 其核心特征是用非局部交换算子 $\Pi$ 替代传统的局部 Robin 迹交换, 从而对网格细化具有鲁棒性, 且不受子域划分中交叉点的影响. 尽管 GOSM 对网格细化健壮, 但其线性求解的收敛性仍可能随子域数目增加或因共振而恶化. 粗空间校正是克服此类困难的天然手段. 近年来, 重叠型 Schwarz 方法的粗空间构造取得了显著进展, 能够处理共振, 但其离线构造代价高昂且难以直接移植到非重叠方法. 已有的非重叠子结构粗空间策略多针对正定问题, 少数涉及 Helmholtz 问题, 但均不适用于结构特殊的 GOSM. 本文正是为 GOSM 发展一种在连续水平上的粗空间预处理策略.

令 $\Omega$ 划分为非重叠 Lipschitz 子域 $\Omega_1,\dots,\Omega_J$, 骨架 $\Sigma := \partial\Omega_1 \cup \dots \cup \partial\Omega_J$. 引入乘积空间 $\mathbf{H}(\Omega) := \prod_j H^1(\Omega_j)$, $\mathbf{H}(\Sigma) := \prod_j H^{1/2}(\partial\Omega_j)$, 并定义块对角算子 $A_+ = \operatorname{diag}(A_{\Omega_j,+})$, $T_+ = \operatorname{diag}(T_{\Omega_j,+})$ 其中 $A_{\Omega_j,+}$ 和 $T_{\Omega_j,+}$ 分别对应 $\kappa^2$ 带正号的能量内积与 Dirichlet-to-Neumann 映射; 边界迹算子 $B = \operatorname{diag}(B_{\Omega_j})$. 选择阻抗算子 $T:\mathbf{H}(\Sigma)\to\mathbf{H}(\Sigma)'$ 为块对角正定自伴且 $T - T_+$ 紧. 非局部交换算子定义为 $\Pi := 2T R(R^*TR)^{-1}R^* - \mathrm{Id}$, 其中 $R:H^{1/2}(\Sigma)\to\mathbf{H}(\Sigma)$ 为限制算子, 满足 $\Pi^2 = \mathrm{Id}$ 且 $\|\Pi p\|_{T^{-1}} = \|p\|_{T^{-1}}$. 局部散射算子 $S:\mathbf{H}(\Sigma)'\to\mathbf{H}(\Sigma)'$ 通过

$$S := 2i T B (A - i B^* T B)^{-1}B^* + \mathrm{Id}$$

定义, 其中 $A = \operatorname{diag}(A_{\Omega_j})$ 来自 Helmholtz 双线性形式, 它满足 $\|S p\|_{T^{-1}} \le \|p\|_{T^{-1}}$, 且在纯 Neumann 边界时等距. 最终的骨架方程为

$$(\mathrm{Id} + \Pi S) p = f,$$

等价于原边值问题. GOSM 的一个独特性质是 $S - i\mathrm{Id}$ 是紧算子, 从而 $(\mathrm{Id} + \Pi S)^4 + 4\mathrm{Id}$ 也是紧的. 该紧性是传统 OSM 所不具备的, 为构造粗空间预处理与证明 GMRES 的超线性收敛提供了基础. 本文在无穷维连续层次上分析这一性质, 设计粗空间预处理, 并给出预处理后 GMRES 的收敛估计; 离散对应物将在后续工作中给出.

2. 主要定理或主要结果#

本文的主要理论结果集中在第 5 节及后续的粗空间构造. 由于提供的 PDF 片段仅包含至第 5 节及第 6 节标题, 详细的粗空间预处理收敛定理未在提供文本中完全呈现, 以下首先概述已明确呈现的结论, 再依据摘要提及后续结果.

  1. 紧性结果:

    • 引理 5.1 表明, 若将 $A$ 替换为 $A_+$ 且 $T$ 替换为 $T_+$, 散射算子退化为纯虚单位算子: $2i T B(A_+ - i B^* T_+ B)^{-1}B^* + \mathrm{Id} = i\mathrm{Id}$.
    • 引理 5.2 证明 $S - i\mathrm{Id}$ 是紧的. 证明基于 $T_+ - T$ 紧 (假设) 以及 $A_+ - A$ 紧 (因 $H^1(\Omega_j) \hookrightarrow L^2(\Omega_j)$ 紧且边界项为低阶) 的事实.
    • 推论 5.3 由此推出 $(\mathrm{Id} + \Pi S)^4 + 4\mathrm{Id}$ 是紧算子. 利用 $\Pi^2 = \mathrm{Id}$ 有 $(\mathrm{Id} + i\Pi)^4 = -4\mathrm{Id}$, 与紧性差相减即得.

  2. GMRES 超线性收敛:

    • 采用范数 $\|\cdot\|_{T^{-1}}$, GMRES 的第 $n$ 步残差 $r_n$ 满足 $\|r_n\|_{T^{-1}} \le \|r_0\|_{T^{-1}} \prod_{j=1}^{\lfloor n/4\rfloor} \frac{\sigma_j(4\mathrm{Id} + (\mathrm{Id} + \Pi S)^4)}{\gamma_\star^4}$, 其中 $\gamma_\star$ 是强制常数 (见 (25) 式, $\gamma_\star \ge \sqrt{2}\alpha/(\lambda_{\max}^2 + (2\|a\|/\lambda_{\min})^2)$). 此估计应用了 Moret 定理 (定理 5.4): 若 $\mathrm{Id} + \Pi S$ 可逆且其某次幂与标量恒等之差紧, 则 GMRES 残差衰减由该紧算子的奇异值乘积控制. 由于 $4\mathrm{Id} + (\mathrm{Id} + \Pi S)^4$ 紧, $\sigma_j \to 0$, 故残差收敛快于任何几何速率, 即超线性收敛.
    • 埃尔曼几何界 (27): $\|r_n\|_{T^{-1}} \le (1 - (\gamma_\star/2)^2)^{n/2}\|r_0\|_{T^{-1}}$ 作为备选保底估计.

  3. Schatten p 类估计:

    • 若进一步假设 $A - A_+: \mathbf{H}(\Omega) \to \mathbf{H}^1(\Omega)'$ 和 $T - T_+: \mathbf{H}(\Sigma) \to \mathbf{H}(\Sigma)'$ 属于 Schatten p 类 ($p \ge 1$), 则引理 5.6 证明 $S - i\mathrm{Id}$ 和 $4\mathrm{Id} + (\mathrm{Id} + \Pi S)^4$ 也属于 $p$ 类, 并给出显式范数界: $\|S - i\mathrm{Id}\|_{C_p} \le \sqrt{2}E$, $\|4\mathrm{Id} + (\mathrm{Id} + \Pi S)^4\|_{C_p} \le 4(4+6E+4E^2+E^3)E$, 其中 $E = (\|A - A_+\|_{C_p} + \|T - T_+\|_{C_p})/(\sqrt{2}\beta)$ 且 $\beta = \|(A - iB^*TB)^{-1}\|^{-1}$. 结合奇异值的算术-几何平均不等式 (引理 5.5), 可进一步给出 $\|r_n\|_{T^{-1}}/\|r_0\|_{T^{-1}} \le (n^{-1/p} \|4\mathrm{Id} + (\mathrm{Id} + \Pi S)^4\|_{C_p} / \gamma_\star^4)^{\lfloor n/4\rfloor}$, 量化了收敛速率.

  4. 粗空间预处理 (摘要及文章结构指明): 本文基于紧性观察, 提出一种构造 $(\mathrm{Id} + \Pi S)$ 的参数化 (parametrix) 的方法, 通过粗空间投影消除紧部分, 得到预处理算子 $M$, 使得 $M(\mathrm{Id} + \Pi S) = \mathrm{Id} + \text{紧}$, 从而预处理后的系统在 GMRES 下具有网格无关与子域数无关的快速收敛. 具体的构造与收敛定理位于第 6 节, 但提供文本截止于引理 5.6, 第 6 节仅有标题, 故此处无法给出详细结论.

3. 研究方法、关键技术和核心工具#

本文的技术核心在于巧妙利用 GOSM 特有的紧性结构, 将谱分析与 Schatten 类理论引入 Krylov 收敛性研究. 主要方法与工具有:

  1. 函数空间与算子代数框架: 严格在无限维 Hilbert 空间 $\mathbf{H}(\Omega), \mathbf{H}(\Sigma), \mathbf{H}(\Sigma)'$ 上工作. 定义了基于正定能量内积 $A_+$ 与 Dirichlet-to-Neumann 映射 $T_+$ 的加权范数, 并构造阻抗算子 $T$ 和散射算子 $S$ 使得算子间的关系具有清晰的紧扰动结构. 交换算子 $\Pi$ 的定义 (20) 保证了 $\Pi^2 = \mathrm{Id}$ 且 $\Pi$ 是 $T^{-1}$-等距, $S$ 是 $T^{-1}$-压缩, 构成有界线性算子的基本性质.

  2. 关键紧性分析: 核心障碍在于传统 OSM 的局部交换无法产生散射算子与 $i\mathrm{Id}$ 的紧偏差. 本文通过精确的代数恒等变形 (引理 5.1 证明) 将 $S$ 表示成 $i\mathrm{Id}$ 加上一个显式的紧扰动:

    $$S - i\mathrm{Id} = 2i T B (A - i B^* T B)^{-1} (A_+ - A - i B^*(T_+ - T)B) (A_+ - i B^* T_+ B)^{-1} B^*.$$

    由于 $T_+ - T$ 紧 (假设) 和 $A_+ - A$ 紧 (因 $H^1$ 紧嵌入 $L^2$ 及边界项的 Hilbert-Schmidt 性质), 根据紧算子的理想性质即得 $S - i\mathrm{Id}$ 紧.

  3. 谱与多项式逼近: 为了证明 GMRES 超线性收敛, 作者不直接分析 $\mathrm{Id} + \Pi S$, 而是考察其四次幂 $(\mathrm{Id} + \Pi S)^4$. 这是因为 $\Pi^2 = \mathrm{Id}$ 保证了 $(\mathrm{Id} + i\Pi)^2 = 2i\Pi$ 从而 $(\mathrm{Id} + i\Pi)^4 = -4\mathrm{Id}$, 故 $(\mathrm{Id} + \Pi S)^4 + 4\mathrm{Id}$ 恰为紧算子. 这为运用 Moret 定理 (定理 5.4) 创造了条件: 对于 Hilbert 空间 $H$ 上的可逆算子 $L$, 若 $L - \lambda\mathrm{Id}$ 紧, 则对任意 $g \in H$, 有

    $$\min_{Q\in P_n, Q(0)=1} \|Q(L)g\| \le \|g\| \prod_{j=1}^n \sigma_j(L-\lambda\mathrm{Id})\, \sigma_j(L^{-1}).$$

    取 $L = (\mathrm{Id}+\Pi S)^4$, $\lambda = -4$, 即得超线性收敛估计 (31). 该技巧的关键是将紧性从 $S$ 通过代数组合传递至整个算子, 从而触及 Krylov 方法收敛的本质——奇异值的衰减.

  4. Schatten p 类量化: 为得到更精确的收敛率, 作者进一步假设 $A - A_+$ 和 $T - T_+$ 属于 Schatten $p$ 类. 通过算子范数的细致估计及逆算子的有界性, 导出 $S - i\mathrm{Id}$ 与 $(\mathrm{Id}+\Pi S)^4 + 4\mathrm{Id}$ 的 Schatten 范数界 (引理 5.6). 结合算术-几何平均不等式, 将奇异值乘积转化为收敛速率的上界, 给出了可显式计算的步数-残差关系. 这种量化分析为评估预处理构造的数值效果提供了理论依据.

  5. 粗空间预处理构造思路 (从摘要及上下文推断, 虽细节未给出): 基于 $(\mathrm{Id}+\Pi S)^4$ 是恒等加紧的事实, 作者可能采用类似于“近似逆”或“splitting”的方法, 在有限维粗空间中捕捉该紧算子的主要分量, 构造预处理器 $M$, 使得 $M(\mathrm{Id} + \Pi S) = \mathrm{Id} + K$, 其中 $K$ 紧且范数小. 这种构造利用了 GOSM 的散射算子紧扰动的独特结构, 是传统方法无法实现的.

整体证明框架: 从线性算子的代数分解出发, 借助紧性建立谱衰减; 利用 Krylov 方法的多项式极小特性, 通过 Moret 定理将紧算子奇异值与收敛速度挂钩; 最后在 Schatten 类假设下量化衰减速率. 文章的分析均在连续水平进行, 为离散情形的预处理设计提供了严格的数学基础.

4. 与之前工作的比较#

与传统优化施瓦茨方法 (OSM) 及现有粗空间策略相比, 本文的贡献与推进主要体现在以下几个方面:

  1. 与传统 OSM 的本质差异: 传统 OSM (包括各种 Robin 参数调优变体) 在每个界面通过局部交换 Robin 迹来耦合子域, 其散射算子 $S$ 不具备 $S - i\mathrm{Id}$ 紧的性质. 这是因为局部 Robin 边界条件导致 $S$ 与无界伪微分算子相关联, 与 $i\mathrm{Id}$ 的差在恰当范数下未必紧. GOSM 通过非局部交换算子 $\Pi$, 将散射算子与 $i\mathrm{Id}$ 的区别归化为紧的, 从而为本文使用紧性构造粗空间与证明超线性收敛提供了可能性. 换言之, 本文利用了 GOSM 特有的代数结构, 这是所有传统局部 OSM 所缺失的.

  2. 与重叠型 Schwarz 粗空间对比: 文献 [33, 19, 18, 20, 22, 2] 针对重叠型区域分解发展了一系列能处理共振的粗空间, 如基于广义特征值问题的自适应粗空间. 这些方法对 Helmholtz 问题是有效的, 但其粗空间构造通常需要求解局部特征值问题, 离线计算量较大, 且强依赖于重叠区域. 它们难以直接移植到非重叠 DDM, 因非重叠方法中不存在自然的重叠区域来提取粗基函数. 本文的方法则建立在非重叠 GOSM 框架上, 通过分析连续算子结构构造粗空间, 不受重叠假设的限制.

  3. 与非重叠子结构粗空间对比: 已有的非重叠子结构粗空间 (如 [25, 8, 34] 及其中文献) 多数针对对称正定问题, 利用能量极小与延拓算子构造. 针对 Helmholtz 问题的少数工作 (如 FETI-H [12, 13, 14]) 通常需要对偶变量处理, 其粗空间依赖于对偶空间的特定投影. 但这些技术不适用于 GOSM, 因为 GOSM 的骨架方程 $\mathrm{Id} + \Pi S$ 既非对称也非标准 Galerkin 形式; 直接套用上述方法会破坏 GOSM 特殊的非局域耦合结构和紧性. 本文专为 GOSM 设计的粗空间充分利用了紧性: 预处理后的算子成为恒等加紧扰动, 从而使 Krylov 子空间方法收敛且迭代次数不随网格或子域数显著增长.

  4. 相对于先前 GOSM 工作的推进: 文献 [4, 5, 6] 建立了 GOSM 的基本理论, 证明了其适定性和网格鲁棒性, 并给出了埃尔曼型几何收敛界. 但这些工作中并未涉及粗空间校正. 本文首次在 GOSM 中引入粗空间预处理, 并证明了 GMRES 的超线性收敛, 将收敛速度从单纯几何收敛 (可能随参数退化) 提升为超线性. 同时, 通过 Schatten 类分析, 给出了可量化的收敛率, 为实际离散实现提供了明确的理论指导.

  5. 代价与局限: 本文的分析在连续无限维水平上进行, 回避了离散化细节, 因此得出的紧性、收敛估计等结论尚需在离散实现中验证. 粗空间的具体构造 (可能需要求解特征值或近似奇异值分解) 的离线代价未在本文讨论; 作者提及将在“forthcoming contribution”中给出离散对应物. 另外, 紧性依赖于 $T - T_+$ 和 $A - A_+$ 的紧性, 在离散有限元情形这些算子成为有限秩, 紧性自动满足, 因此理论结果对离散算子的适用性预期良好. 总体而言, 本文为 GOSM 的预处理提供了一种原理性的新途径, 其核心创新在于挖掘并利用散射算子的紧扰动特性.

1. 研究对象和背景#

本文研究二维标量波在周期衍射光栅上的散射问题. 令 $L>0$, $\gamma:\mathbb{R}\to\mathbb{R}^2$ 为 $C^{1,1}$ 嵌入, 满足 $\gamma(t+2\pi)=\gamma(t)+L\mathbf{e}_1$, 其中 $\mathbf{e}_1=(1,0)$. 由此生成周期曲线 $\Gamma_{\mathrm{per}}:=\gamma(\mathbb{R})$ 及其一个周期段 $\Gamma:=\gamma([0,2\pi])$. 记 $\Omega^+$ 为 $\mathbb{R}^2\setminus\Gamma_{\mathrm{per}}$ 中满足存在 $H^+\in\mathbb{R}$ 使得 $\mathbb{R}\times(H^+,\infty)\subset\Omega^+$ 的连通分支, 而 $\Omega^-$ 为存在 $H^-\in\mathbb{R}$ 使得 $\mathbb{R}\times(-\infty,H^-)\subset\Omega^-$ 的分支. 设 $\beta\in\mathbb{R}$ 为给定的相位常数, 定义 $\beta$-准周期连续函数空间 $C_\beta(\Gamma_{\mathrm{per}}):=\{\varphi\in C(\Gamma_{\mathrm{per}}):\varphi(\mathbf{x}+L\mathbf{e}_1)=\varphi(\mathbf{x})e^{i\beta}\}$, 并装备范数 $\|\varphi\|_{C_\beta(\Gamma_{\mathrm{per}})}:=\|\varphi\|_{C(\Gamma)}$. 对给定的波数 $k\in\mathbb{R}$ 与边界数据 $g\in C_\beta(\Gamma_{\mathrm{per}})$, 所考虑的衍射问题 $(\mathrm{P}_k)$ 为

$$ \begin{cases} -\Delta u - k^2 u = 0 & \text{在 } \Omega^+ \text{ 内},\\ u(\mathbf{x}+L\mathbf{e}_1)=u(\mathbf{x})e^{i\beta} & \text{在 } \Omega^+ \text{ 内},\\ u = g & \text{在 } \Gamma_{\mathrm{per}} \text{ 上},\\ u \text{ 满足向上的辐射条件}. \end{cases} $$

向上辐射条件的形式化定义借助 Rayleigh 展开: 对满足 Helmholtz 方程及准周期条件的函数 $u$, 在区域 $\mathbb{R}\times(H^+,\infty)$ 上可唯一展开为

$$ u(\mathbf{x}) = \sum_{s\in\mathbb{Z}\setminus\sigma_*(k)} A_s^+ e^{i k_s x_1 + i\sqrt{k^2-k_s^2}\,x_2} + \sum_{s\in\mathbb{Z}\setminus\sigma_*(k)} B_s^+ e^{i k_s x_1 - i\sqrt{k^2-k_s^2}\,x_2} + \sum_{s\in\sigma_*(k)} A_s^+ e^{i k_s x_1} + \sum_{s\in\sigma_*(k)} B_s^+ x_2 e^{i k_s x_1}, $$

其中 $k_s:=(\beta+2s\pi)/L$, $\sigma_*(k):=\{s\in\mathbb{Z}: k^2-k_s^2=0\}$ 为 Wood 异常指标集 (至多含 2 个元素); $u$ 满足向上的辐射条件当且仅当对所有 $s\in\mathbb{Z}$ 有 $B_s^+=0$. 类似可定义向下辐射条件.

此类问题在衍射光栅及超表面的建模中起核心作用. 经典理论 (Kirsch, 1993) 表明, 对 Dirichlet 边界条件, 无悬垂 (overhang-free) 几何条件 $\nu_2(\mathbf{x})>0$ (其中 $\boldsymbol{\nu}$ 为指向 $\Omega^+$ 的单位外法向) 可保证齐次问题 $(\mathrm{P}_k)$ 仅有平凡解, 从而原问题唯一可解.

边界积分方程方法是求解 $(\mathrm{P}_k)$ 的有效途径之一, 其基础是准周期 Green 函数. 对 $k\in\mathbb{R}\setminus\Lambda$ (这里 $\Lambda:=\{k\in\mathbb{R}: k^2-k_s^2=0,\,s\in\mathbb{Z}\}$ 为 Wood 异常频率集), 标准的辐射准周期 Green 函数由 Rayleigh 级数给出

$$ G_k(\mathbf{x}) = \frac{i}{2L}\sum_{s=-\infty}^{\infty} \frac{1}{\sqrt{k^2-k_s^2}} e^{i k_s x_1 + i\sqrt{k^2-k_s^2}\,|x_2|}, $$

该级数在 $L^p_{\mathrm{loc}}(\mathbb{R}^2)$ ($1\le p<\infty$) 中收敛, 并满足 $(-\Delta-k^2)G_k = F_\#:= \sum_{n=-\infty}^{\infty} e^{i n\beta}\delta_{nL\mathbf{e}_1}$ 于分布意义下. 然而, $G_k$ 作为频率的函数在 $\Lambda$ 处奇异: 当 $k\to k_*\in\Lambda$ 时, 级数中对应于 $s\in\sigma_*(k_*)$ 的各项因分母 $\sqrt{k^2-k_s^2}\to0$ 而发散, 导致 $G_k$ 在 $L^p_{\mathrm{loc}}$ 乃至分布意义下均无极限. 这使得基于标准准周期 Green 函数的边界积分方程离散无法得到在包含 Wood 异常的频率区间上一致有效的误差估计, 因为核的奇异性破坏了有界性.

为克服此困难, 已有的工作发展了若干修正策略: 平移准周期 Green 函数 (shifted quasi-periodic Green functions, 如 Bruno–Haslam [8]) 通过差分平移自由空间基本解并补全缺失的 Rayleigh 模式来避免奇异性, 但未建立严格的频率一致误差分析; 混合空间/谱视角的方法 (如 Oschmann–Holzmann–Xiao [9,10]) 显式分离奇异 Rayleigh 项, 利用 Woodbury–Sherman–Morrison 公式与极限过程处理, 提供了适定的数值格式, 但同样缺乏跨越 Wood 异常的频率一致收敛性与条件数估计; 窗函数 Green 函数法 (如 Bruno–Shipman–Turc [25]) 则通过有限秩模态修正实现超代数收敛, 但也未证明误差对频率的一致有界性. 总之, 在包含 Wood 异常的紧频率区间上建立严格的、与频率无关的误差估计和条件数界, 仍是该领域的一个重要空白. 本文旨在填补这一空白: 提出一种修改的准周期 Green 函数构造与相应的合场边界积分方程, 并基于 Nyström 离散建立一整套频率一致的适定性与误差分析.

2. 主要定理或主要结果#

本文的主要结果由两个定理及相应的推论构成.

定理 2.6 (连续层面边界积分方程的适定性与频率连续性). 设 $k\in\mathbb{R}$, $\eta>0$, 并假设齐次问题 $(\mathrm{P}_k)$ (即 $g=0$) 仅有平凡解. 则 (i) 非齐次问题 $(\mathrm{P}_k)$ 对任意 $g\in C_\beta(\Gamma_{\mathrm{per}})$ 均唯一可解. (ii) 对任意有限子集 $\sigma\subset\mathbb{Z}$ 满足 $k\in(\mathbb{R}\setminus\Lambda)\cup\Lambda_\sigma$ (这里 $\Lambda_\sigma:=\{k\in\Lambda: \sigma_*(k)\subset\sigma\}$), 定义在 $C_\beta(\Gamma_{\mathrm{per}})\times C^\sigma$ 上的边界积分方程

$$ (\mathrm{Q}_k)\qquad (I + \mathcal{A}_k)\begin{pmatrix}\varphi\\ \mathbf{c}\end{pmatrix} = \begin{pmatrix}2g\\ \mathbf{0}\end{pmatrix} $$

唯一可解, 其中 $\mathcal{A}_k = \begin{pmatrix} D_k - i\eta S_k & R \\ T & -\operatorname{diag}\big(1+\sqrt{k^2-k_s^2}\big)_{s\in\sigma} \end{pmatrix}$, $S_k$, $D_k$ 是基于修改的准周期 Green 函数 $\widehat{G}_k$ 的单层位势与双层位势算子, $R$, $T$ 为有限维修正算子 (具体定义见原文). 其解 $(\varphi,\mathbf{c})$ 通过位势表达式

$$ u_k(\mathbf{x}) = \int_\Gamma \left(\frac{\partial\widehat{G}_k}{\partial\nu(\mathbf{y})}(\mathbf{x}-\mathbf{y}) - i\eta \widehat{G}_k(\mathbf{x}-\mathbf{y})\right) \varphi(\mathbf{y})\,\mathrm{d}s(\mathbf{y}) + \frac12 \sum_{s\in\sigma} c_s e^{i k_s x_1}, \quad \mathbf{x}\in\Omega^+, $$

给出 $(\mathrm{P}_k)$ 的唯一解. 此外, 若 $J\subset\mathbb{R}$ 为一区间, 且对于所有 $k\in J$, 齐次问题 $(\mathrm{P}_k)$ 仅零解, 则对任一连续族 $\{g_k\}_{k\in J}\subset C_\beta(\Gamma_{\mathrm{per}})$, 相应的解 $u_k$ 在 $C_{\mathrm{loc}}(\Omega^+)$ 中关于 $k$ 连续, 即对每个 $k\in J$ 与紧子集 $V\subset\Omega^+$,

$$ \sup_{\mathbf{x}\in V} |u_k(\mathbf{x}) - u_{\kappa}(\mathbf{x})| \to 0 \quad (\kappa\to k). $$

该定理表明, 通过引入有限维校正项, 可将问题转化为一个在包含 Wood 异常频率的集合上具有连续依赖性的积分方程, 从而为一致数值分析奠定基础.

定理 2.8 (全离散 Nyström 格式的频率一致误差与条件数界). 设 $K$ 为 $\mathbb{R}$ 中的紧子集, 且对所有 $k\in K$ 齐次问题 $(\mathrm{P}_k)$ 只有零解. 令 $\eta>0$, 选取有限子集 $\sigma\subset\mathbb{Z}$ 使 $K\subset(\mathbb{R}\setminus\Lambda)\cup\Lambda_\sigma$. 假设 $\{g_k\}_{k\in K}\subset C^{0,1}_\beta(\Gamma_{\mathrm{per}})$ (即 $g_k\circ\gamma$ 为 Lipschitz 连续) 且映射 $k\mapsto g_k$ 从 $K$ 到 $C^{0,1}_\beta(\Gamma_{\mathrm{per}})$ 连续. 此外设 $\gamma\in C^{2,\alpha}(\mathbb{R})$ 对某 $\alpha\in(0,1]$. 则存在正整数 $N$, $M$, 常数 $C>0$ 及 $\xi>0$, 使得对任意 $n\ge N$, $m\ge M$ 和 $k\in K$, (i) 线性系统 $(\mathrm{Q}_k^{(n,m)})$ (其矩阵 $B^{(n,m)}_k\in\mathbb{C}^{(2n+\#\sigma)\times(2n+\#\sigma)}$ 由 Ewald 表示与特殊求积规则导出, 列于原文公式中) 唯一可解; (ii) 若以 $(\varphi_k,\mathbf{c}_k)$ 记连续问题 $(\mathrm{Q}_k)$ 的解, 而以 $(\widetilde{\boldsymbol{\varphi}}^{(n,m)}_k,\mathbf{c}^{(n,m)}_k)$ 记离散系统解, 则通过插值公式

$$ \varphi^{(n,m)}_k(\gamma(t)) = e^{i\beta t/(2\pi)} \sum_{j=0}^{2n-1} \left( R_j^{(n)}(t) \frac{i\eta}{2\pi}|\gamma'(t_j^{(n)})| - \frac{\pi}{n} H_{k,m}(t, t_j^{(n)}) \right) (\widetilde{\boldsymbol{\varphi}}^{(n,m)}_k)_j - \sum_{s\in\sigma} (\mathbf{c}^{(n,m)}_k)_s e^{i k_s (\gamma(t))_1} + 2g_k(\gamma(t)) $$

重构的近似解满足误差估计

$$ \sup_{k\in K} \big( \|\varphi_k - \varphi_k^{(n,m)}\|_{C_\beta(\Gamma_{\mathrm{per}})} + \|\mathbf{c}_k - \mathbf{c}_k^{(n,m)}\| \big) \le C\big( n^{-\alpha} + e^{-\xi m} \big); $$

(iii) 矩阵 $B^{(n,m)}_k$ 的 $\ell^\infty$ 条件数在 $k\in K$, $n\ge N$, $m\ge M$ 下一致有界, 即存在常数 $C_{\mathrm{cond}}$ 使得

$$ \sup_{k\in K, n\ge N, m\ge M} \kappa_{\infty}(B^{(n,m)}_k) \le C_{\mathrm{cond}}. $$

这里 $t_j^{(n)}:=j\pi/n$, $R_j^{(n)}$ 为仅依赖于 $n$ 与 $\zeta$ 的特殊插值函数, $H_{k,m}$ 为基于 Ewald 表示的光滑核函数 (见原文). 误差界由两部分构成: $n^{-\alpha}$ 反映 Nyström 离散的代数收敛阶, 受限于边界曲线的 $C^{2,\alpha}$ 正则性; $e^{-\xi m}$ 为对被截断的 Ewald 和的指数收敛率. 条件数的一致有界性保证了该数值格式在跨越 Wood 异常频率时的数值稳定性.

3. 研究方法、关键技术和核心工具#

本文的核心技术思路分为三个层次: 修改的准周期 Green 函数的构造与分析、基于该 Green 函数的合场边界积分方程的适定性证明、以及全离散 Nyström 格式的误差与条件数分析. 以下分段阐述每个步骤的关键工具与创新点.

1. 修改的准周期 Green 函数及频率连续性分析.

标准准周期 Green 函数在 Wood 异常频率处奇异的根源在于 Rayleigh 展开中 $s\in\sigma_*(k)$ 的项含有分母 $\sqrt{k^2-k_s^2}\to0$. 作者首先在 命题 2.5 中给出了一个对所有 $k\in\mathbb{R}$ 均有定义的准周期 Green 函数:

$$ G_k(\mathbf{x}) = \frac{i}{2L}\sum_{s\in\mathbb{Z}\setminus\sigma_*(k)} \frac{e^{i k_s x_1 + i\sqrt{k^2-k_s^2}\,|x_2|}}{\sqrt{k^2-k_s^2}} - \frac{1}{2L}\sum_{s\in\sigma_*(k)} |x_2| e^{i k_s x_1}. $$

在 $k\in\Lambda$ 时, 该函数并不满足远场辐射条件 (包含 $x_2$ 的线性增长项), 但它是方程 $(-\Delta-k^2)G_k = F_\#$ 的分布解. 这一非辐射 Green 函数为构造修正积分方程提供了出发点.

关键观察: 尽管 $G_k$ 本身在 $\Lambda$ 处关于 $k$ 并非连续, 但若将对应于 Wood 异常指标的 Rayleigh 项显式分离, 则剩余部分具有良好的连续性质. 具体地, 定义修正的 Green 函数

$$ \widehat{G}_k(\mathbf{x}) := G_k(\mathbf{x}) - \frac{i}{2L}\sum_{s\in\sigma\setminus\sigma_*(k)} \frac{e^{i k_s x_1}}{\sqrt{k^2-k_s^2}}, $$

其中 $\sigma$ 是包含 $\sigma_*(k)$ 的有限指标集. 空间奇异性的分析与 引理 3.1 (Bruno–Reitich 型一致收敛) 表明, 去掉有限个奇异模式后, 级数在远离点源的区域对 $k$ 一致收敛. 在 命题 3.2 中, 通过精细的位势估计证明了如下核心结果: 对任一固定的 $k\in\mathbb{R}$, 当 $\kappa\to k$ 时,

$$ G_{\kappa} - \frac{i}{2L}\sum_{s\in\sigma_*(k)} \frac{e^{i k_s x_1}}{\sqrt{\kappa^2-k_s^2}} - G_k \to 0 \quad \text{在 } C^{1,\alpha}_{\mathrm{loc}}(\mathbb{R}^2) \text{ 中}. $$

证明的关键是将差函数 $v_n$ 满足的方程右端源项分解为体积项与边界项, 利用 $L^p$ 估计与内 $W^{2,p}$ 估计及 Morrey–Sobolev 嵌入, 克服了在 Wood 异常点附近级数项无法绝对收敛的困难. 此连续性结果直接传递到积分算子 $S_k$ 和 $D_k$: 命题 3.3 确立了它们是从 $C_\beta(\Gamma_{\mathrm{per}})$ 到自身的紧算子, 且依赖于 $k$ 连续; 若 $\gamma\in C^{2,\alpha}$, 则作为 $C^{0,1}_\beta(\Gamma_{\mathrm{per}})$ 到自身的算子也具有同样的连续紧性. 这为后续使用紧扰动理论奠定基础.

2. 合场边界积分方程的构造与适定性.

利用 $\widehat{G}_k$ 直接构造单、双层位势则会因为 $\widehat{G}_k$ 中减去的非 Helmholtz 项而破坏解的散射性质. 作者巧妙地引入了一个有限维修正项来恢复辐射条件. 具体而言, 定义算子矩阵

$$ \mathcal{A}_k = \begin{pmatrix} D_k - i\eta S_k & R \\ T & -\operatorname{diag}(1+\sqrt{k^2-k_s^2})_{s\in\sigma} \end{pmatrix}, $$

其中 $R:C^{\sigma}\to C_\beta(\Gamma_{\mathrm{per}})$ 为有限维嵌入算子 $(R\mathbf{c})(\mathbf{x})=\sum_{s\in\sigma} c_s e^{i k_s x_1}$, $T:C_\beta(\Gamma_{\mathrm{per}})\to C^{\sigma}$ 通过边界积分提取相应模态的系数. 该设计使得对应于 $s\in\sigma$ 的向外传播波模式能够被正确激发.

定理 2.6 的证明基于以下步骤: 首先, 在假设原边值问题唯一可解的条件下, 可证明 $I+\mathcal{A}_k$ 在 $C_\beta(\Gamma_{\mathrm{per}})\times C^{\sigma}$ 上的单射性. 这是因为当右端项为零时, 所重构的位势满足齐次 Helmholtz 方程与齐次边界条件, 且其远场行为由 $\mathbf{c}=0$ 及辐射条件唯一确定; 结合唯一可解假设即得零解. 进而, 通过 Fredholm 二择一, 单射性结合紧性 ($\mathcal{A}_k$ 紧) 蕴含满射, 从而方程唯一可解. 频率连续性的证明则利用 $\mathcal{A}_k$ 对 $k$ 的连续依赖与解的存在唯一性的稳定性. 这样, 原问题被转化为一个在包含 Wood 异常频率的区间上良好适定的等价积分方程.

3. Nyström 离散与一致误差分析.

离散层面的主要困难有二: 第一, 核函数 $\widehat{G}_k$ 在 $\Gamma$ 上具有对数奇异性, 直接使用经典 Nyström 方法会损失精度; 第二, 级数表示的 Green 函数求值需高效精确实现, 且需保证截断误差对频率一致可控. 作者采用了以下技术组合.

  • Ewald 表示与奇性分离. 将 $\widehat{G}_k$ 及其法向导数通过 Ewald 分裂改写为空间域与频率域快速衰减级数之和, 显式分离出光滑部分与对数奇性部分. 具体地, 核函数 $H_{k,m}(t,\tau)$ 在截断参数 $m$ 下逼近真实的积分核, 其中 $W_{k,m}$ 利用互补误差函数 $\operatorname{erfc}$ 与有限模态和表达, 而余项由含指数衰减的级数及窗函数 $\chi$ 处理. 这种表达使得对数奇性被集中在 $E_1$ 项中, 其余项均为光滑或至少 $C^{1,\alpha}$.

  • 特殊求积规则. 对于对数奇性 $E_1(\zeta^2 r^2)$, 作者构造了基于等距节点 $t_j^{(n)}=j\pi/n$ 与周期三角插值的求积公式 (见 (2.4) 中的 $R_j^{(n)}$). 该规则本质上利用了对数核在周期域上的展开, 通过引入辅助参数 $\zeta$ 及误差函数权重, 可达到对光滑密度的超代数精度, 同时将奇异性吸收到可精确计算的系数 $\widehat{E}_p$ 中. 整个离散矩阵 $B^{(n,m)}_k$ 的构造保证了即使 $k$ 接近或等于 Wood 异常频率, 矩阵元素仍一致有界且可计算.

  • 误差分解与紧性扰动. 误差分析分两步: 首先, 将连续算子 $\mathcal{A}_k$ 与离散算子 $\mathcal{A}_k^{(n,m)}$ (对应于矩阵 $B^{(n,m)}_k-I$) 的差分解为截断误差 (由 $m$ 控制) 与求积误差 (由 $n$ 控制). 截断误差分析依赖 Ewald 和的指数收敛性质: 对于 $C^{2,\alpha}$ 曲线, 被截断的模态对核的影响由因子 $e^{-\xi m}$ 控制; 求积误差则利用解与核的正则性: 当 $\gamma\in C^{2,\alpha}$ 且 $g_k$ 连续 Lipschitz 时, 未知密度 $(\varphi_k,\mathbf{c}_k)$ 具有 $C^{0,\alpha}(\Gamma)$ 光滑性, 而处理对数奇点的求积规则以 $n^{-\alpha}$ 收敛. 其次, 借助算子族 $\mathcal{A}_k$ 的集体紧性 (collective compactness) 与对 $k$ 的连续依赖, 可通过紧扰动理论得出对于足够大的 $n,m$, 离散系统一致可逆, 且误差满足所述上界. 条件数的一致有界性来源于逆算子的一致有界性 (由逆算子的连续性得到) 与近似矩阵族的一致有界性.

综上所述, 本文的方法创新点在于: (a) 利用非辐射准周期 Green 函数减去奇异模式来获得对频率具有连续依赖性的积分核算子; (b) 通过有限维校正恢复正确的辐射条件, 而非使用极限过程或 Woodbury 公式; (c) 将 Ewald 表示与专门处理对数奇性的求积规则相结合, 构造了全离散 Nyström 格式; (d) 在技术层面, 基于 Green 函数的 $C^{1,\alpha}_{\mathrm{loc}}$ 连续性建立了算子族的连续性, 并运用集体紧性获得了对频率一致的误差与条件数估计. 这些步骤共同保证了在包含 Wood 异常的紧凑频率区间上格式的可靠性.

4. 与之前工作的比较#

本文在二维周期光栅散射的边界积分方程解法领域做出了多方面的推进, 主要与以下几类已有工作形成对比.

1. 与标准准周期 Green 函数方法的比较.

传统方法直接使用命题 2.4 中的辐射 Green 函数 $G_k$ 构造边界积分方程 (例如见文献 [3, 11, 22–24]). 该 Green 函数在 Wood 异常频率集 $\Lambda$ 上没有定义, 且当 $k\to k_*\in\Lambda$ 时, 核函数与积分算子无界, 导致无法建立跨 $\Lambda$ 的频率一致误差分析. 本文则通过 $G_k$ 的修改形式 $\widehat{G}_k$ 与有限维修正, 构造了对所有 $k\in(\mathbb{R}\setminus\Lambda)\cup\Lambda_\sigma$ 均有定义且连续依赖 $k$ 的积分算子, 从而在连续与离散层面都获得了频率一致的适定性和误差估计. 这是对经典边界积分方法的一个实质性拓展.

2. 与平移准周期 Green 函数及混合空间/谱方法的比较.

Bruno 与 Haslam [8] 以及 Bruno, Shipman, Turc [13] 等发展了平移准周期 Green 函数方法, 通过对平移自由空间基本解的适当组合构造无奇异的 Green 函数替代物. 这类方法有效地回避了 Wood 异常处的分母为零问题, 并且数值表现良好, 但尚未提供严格的频率一致误差分析或条件数界. 类似地, Oschmann, Holzmann, Xiao 等 [9,10] 提出将准周期 Green 函数分解为奇异 Rayleigh 项与光滑剩余项, 再用 Woodbury–Sherman–Morrison 公式处理奇异部分. 这些工作使计算行之有效, 但同样缺乏对离散格式在 Wood 异常附近误差行为的一致理论保证. 本文首次在二维情形下给出了全离散 Nyström 格式跨越 Wood 异常的频率一致误差界 $C(n^{-\alpha} + e^{-\xi m})$, 并证明了系统矩阵的条件数的一致有界性, 从而将这类方法的数学严格性提升到了一个新的高度.

3. 与窗口 Green 函数方法的比较.

Bruno, Shipman, Turc [25] 提出的窗口 Green 函数方法利用有限秩模态修正来强制 Rayleigh 辐射条件, 能在全谱范围内获得超代数收敛的数值解. 该方法的数学分析证明了超代数收敛性, 但未明确处理频率一致性: 误差常数可能依赖于频率, 尤其是在 Wood 异常附近. 本文的结果表明, 在边界具有 $C^{2,\alpha}$ 正则性时, 我们不仅能获得收敛阶 $n^{-\alpha}$ (当 $\alpha<1$ 时仅为代数阶, 但对于光滑边界可期望更高阶), 更重要的是误差常数与 $k\in K$ 无关. 同时, 条件数的一致有界性确保迭代求解的可靠性. 因此, 本文的结果在频率稳定性分析方面是对窗口格林函数法的重要补充.

4. 与基于自由空间 Green 函数及辅助未知量的方法的比较.

另一类方法避开准周期 Green 函数, 而使用自由空间基本解配合辅助变量或 proxy 源来施加准周期性 (如 [5, 16, 30]). 这类方法可以自然地避免 Wood 异常, 但其误差分析通常依赖截断域的大小与边界条件近似精度, 难以获得完全与频率无关的误差界. 本文由于直接在准周期框架内处理, 有效地利用了 Green 函数的级数结构, 实现了解析的频率一致控制.

5. 局限性与假设条件.

本文的理论建立在几个明确的假设之上: (a) 齐次衍射问题唯一可解, 这可由无悬垂几何条件 $\nu_2>0$ 保证 (定理 2.1); (b) 边界曲线 $\gamma$ 至少具有 $C^{2,\alpha}$ 正则性, 这是为了保证误差阶 $n^{-\alpha}$; (c) 仅考虑二维标量波 (Helmholtz 方程) 和 Dirichlet 边界条件. 与一般三维 Maxwell 散射并不直接等同, 且对于透射问题或其它边界条件需另行推广. 但作者指出的三维非辐射 Green 函数已有初步研究 [13], 这表明本文的框架可能具备向三维拓展的潜力.

总体而言, 本文相较于既有工作的主要推进在于: 首次为一个有限维校正的准周期 Green 函数积分方程提供了全离散 Nyström 格式的频率一致适定性、误差估计与条件数界. 这使得在包含 Wood 异常频率的任何紧区间内, 数值解的精度和稳定性均能得到理论保证, 而不是仅仅依赖经验观察.
