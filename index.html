1. 有限应变弹性的一种统一 CutFEM 格式：能量极小化与角点奇性#

A Unified CutFEM Formulation for Finite-Strain Elasticity: Energy Minimisation and Corner Singularities

作者: Michał Tomasz Wichrowski, Ella Godiva Noomen

类别: math.NA

发布日期: 2026-07-02

arXiv ID: 2607.02334v1

链接: http://arxiv.org/abs/2607.02334v1

摘要翻译#

中文标题: 有限应变弹性的一种统一 CutFEM 格式：能量极小化与角点奇性

摘要翻译: 我们提出一个全变分、模型无关的有限应变弹性 Cut 有限元方法 (CutFEM) 格式。离散问题是增广能量泛函的驻点条件，该泛函由体超弹性能、弱施加边界条件的 Nitsche 项以及鬼罚稳定化项组成。残量和 (对称化的) 切线由该泛函的逐次变分得到。自动微分 (AD) 直接从标量能量密度生成第一 Piola–Kirchhoff 应力张量和弹性张量，避免在更换超弹性模型时手动重新推导。据我们所知，这是第一个结合纯能量、模型无关的构造与自动微分并在非拟合边界处进行精度分析的非拟合有限应变格式。 对每个 Newton 步中求解的线性化问题进行分析，得到了与切割无关的强制性、连续性和 $O(h^{-2})$ 条件数界，并借助 Brezzi–Rappaz–Raviart 框架得到正则解的拟最优收敛定理。数值上，在光滑测试算例上该方法对线性、二次和三次元均达到最优 $h$-收敛。此外，我们使用 Kolosov–Muskhelishvili 特征方程量化了该方法在 Dirichlet–Neumann 混合连接点处的精度极限。精确解的角点奇性对拟合和非拟合方法均以相同的方式限制收敛阶。我们证明局部网格细化可以消除这一限制，非拟合离散继承恢复的最优收敛率和与切割无关的常数。

2. 调和映射流的线性隐式质量集中投影有限元方法的无条件最优误差估计与能量稳定性#

Unconditional Optimal Error Estimates and Energy Stability for a Linearly Implicit Mass-Lumped Projection Finite Element Method for the Harmonic Map Flow

作者: Yongyong Cai, Xingwei Yang

类别: math.NA

发布日期: 2026-07-02

arXiv ID: 2607.02179v1

链接: http://arxiv.org/abs/2607.02179v1

摘要翻译#

中文标题: 调和映射流的线性隐式质量集中投影有限元方法的无条件最优误差估计与能量稳定性

摘要翻译: 我们提出并分析了一种用于调和映射到单位球面的热流的线性隐式质量集中有限元方法。该方法由一个线性预测步骤和随后的节点投影组成，因此能在所有有限元节点处精确保持单位长度约束。预测器是从方程的叉积重表述推导出来的，并证明它与原始公式的质量集中离散化加上一个强制节点正交性的修正项等价，也与切平面格式等价。一个关键之处是在质量和刚度项中一致地使用离散内积。这产生了一个节点正交关系，意味着辅助解在每个节点处都位于单位球面上或其外部。因此，投影是良好定义的，且投影误差在离散 (L^2) 范数下满足一个收缩性质。在笛卡尔矩形和立方体的张量积网格上，节点投影在离散狄利克雷能量下也是非膨胀的，这给出了一个无条件的离散能量耗散律。对于足够光滑的解，我们证明了最优误差估计，无需时间步长与网格尺寸之间的任何耦合条件：该方法在 (\ell^\infty(0,T;L^2)) 中以 (O(\Delta t+h^2)) 阶收敛，在 (\ell^2(0,T;H^1)) 中以 (O(\Delta t+h)) 阶收敛。证明结合了投影误差收缩、求积一致性估计、基于边的消去恒等式以及用于控制非线性项的自举论证。数值实验证实了预测的收敛率和离散能量衰减。

3. 四面体Alfeld剖分上具有可杂交应力的低正则性有限元弹性复形#

Low-regularity finite element elasticity complexes with hybridizable stresses on tetrahedral Alfeld splits

作者: Johnny Guzmán, Xuehai Huang

类别: math.NA

发布日期: 2026-07-02

arXiv ID: 2607.01933v1

链接: http://arxiv.org/abs/2607.01933v1

摘要翻译#

中文标题: 四面体Alfeld剖分上具有可杂交应力的低正则性有限元弹性复形

摘要翻译: 在四面体Alfeld剖分上构造了低正则性的有限元弹性复形。与这类剖分上已有的三维弹性复形相比，此处构造的复形同时降低了Sobolev正则性和多项式次数，并终结于一个无顶点自由度的可杂交$H({\rm div};\mathbb S)$-协调对称应力空间。该构造通过对Alfeld剖分上的多项式de Rham复形应用局部Bernstein–Gelfand–Gelfand论证得到。证明了两类局部多项式弹性复形：一个$H^2$-$H^1({\rm inc})$复形和一个低正则性的$H^1({\rm curl})$-$H({\rm inc}^+)$复形。导出了它们的泡形子复形及维数公式。这些局部正合序列给出了位移空间和不可压缩空间的唯一可解有限元，并给出了相应弹性序列的全局有限元子复形。在最低阶$H^1({\rm curl})$-$H({\rm inc}^+)$有限元复形中，$H({\rm inc}^+;\mathbb S)$-协调张量空间是分片三次的。在同一阶数下，末端应力-位移对恢复了Johnson–Mercier–Křížek元，而该构造涵盖了所有$k\ge1$的高阶可杂交对称应力。第二族给出了所有$k\ge2$的标准弹性序列的低正则性$H^1$-$H({\rm inc})$有限元复形。对两个全局复形均建立了交换插值图。

4. Stokes–Darcy界面问题的流函数–压力虚拟单元法#

Stream function – pressure virtual element methods for the Stokes–Darcy interface problem

作者: Franco Dassi, Rekha Khot, David Mora, Andres E. Rubiano, Ricardo Ruiz-Baier

类别: math.NA

发布日期: 2026-07-02

链接: http://arxiv.org/abs/2607.01622v1

摘要翻译#

中文标题: Stokes–Darcy界面问题的流函数–压力虚拟单元法

摘要翻译: 本文提出了一种用于原始-原始形式耦合Stokes–Darcy系统的全新虚拟单元法（VEM）。在自由流Stokes区域，我们采用流函数构式，该构式本身即满足不可压缩约束并降低计算成本。通过界面处强制质量守恒、法向应力平衡及Beavers–Joseph–Saffman滑移条件，将双调和流函数方程与Darcy压力方程相耦合。得益于VEM处理一般多边形网格的能力，所提方法可以自然地适应不规则界面几何，无需重新网格化或自适应细化。方法的精确性通过若干数值模拟加以验证，其中包括死端过滤和生物人工器官中的网络流应用。
