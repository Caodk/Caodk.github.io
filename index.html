1. 基于CEM-GMsFEM的高对比度非均匀系数问题多尺度建模#

Multiscale modeling for problems with high contrast heterogeneous coefficients by the CEM-GMsFEM

作者: Eric T. Chung, Yalchin Efendiev, Xingguang Jin, Wing Tat Leung, Changqing Ye

类别: math.NA

发布日期: 2026-06-09

arXiv ID: 2606.10524v1

摘要翻译: 本文综述了约束能量最小化广义多尺度有限元方法（CEM-GMsFEM），用于求解具有高度非均匀、高对比度系数的椭圆型偏微分方程。我们通过谱辅助空间详细阐述了多尺度基函数的构造，并结合过采样策略实现局部计算并保证指数误差衰减。我们概述了严格的误差估计，以验证该方法的最优收敛性和稳健性。数值模拟验证了多尺度基函数的指数衰减性质。此外，我们讨论并评述了CEM-GMsFEM的若干最新应用。

Comment: 无

链接: http://arxiv.org/abs/2606.10524v1

1. 研究对象和背景#

许多实际应用涉及具有非均匀系数的偏微分方程，例如非均匀或断裂介质中的达西定律，以及复合材料中的弹性系统。这些应用通常导致扩散系数 $\kappa$ 呈现高对比度和通道状结构，这使得传统数值方法面临巨大挑战：一方面，精细网格需要极大自由度；另一方面，高对比度导致线性代数系统的求解收敛恶化。针对此类问题，多尺度计算方法应运而生，最早由 Hou 和 Wu 提出了多尺度有限元法 (MsFEM) 的概念，将模型信息嵌入有限元空间构造，利用粗细两层嵌套网格。然而，当系数不满足尺度分离假设时，MsFEM 的精度可能严重下降。为了克服这一局限性，Efendiev, Galvis 和 Hou 提出了广义多尺度有限元法 (GMsFEM)，通过在粗子域上求解局部谱问题来降维，对高对比度和通道状系数表现良好。另一方面，Målqvist 和 Peterseim 提出了局部正交分解 (LOD) 方法，利用拟插值算子分离宏观与微观部分，首次实现了对一般 $L^\infty$ 系数的最佳理论逼近。Chung, Efendiev 和 Leung 结合 GMsFEM 与 LOD 的思想，发展了约束能量最小化广义多尺度有限元法 (CEM-GMsFEM)，其核心创新在于用子域上的特征空间投影替代拟插值算子，并通过求解松弛的能量最小化问题构造多尺度基函数，从而避免了解鞍点线性系统。该方法在面对高对比度系数时具有对比度稳健性 (contrast robustness)，且通过局部化计算保证了指数衰减的逼近精度。

本文是一篇综述，旨在全面介绍 CEM-GMsFEM 的构造原理、理论分析和应用进展。研究的模型问题为具有 Dirichlet 边界条件的标准非均匀椭圆方程：

$$-\operatorname{div}(\kappa \nabla u) = f \quad \text{in } \Omega, \qquad u = 0 \quad \text{on } \partial\Omega,$$

其中 $\Omega \subset \mathbb{R}^d$ ($d=2,3$) 为有界 Lipschitz 域，$\kappa$ 满足椭圆性条件，$f$ 为源项。本文详细阐述了 CEM-GMsFEM 的核心模块：两层嵌套网格、基于谱分解的辅助空间构造、过采样 (oversampling) 技术以及基函数的能量最小化构造；给出了严格的理论误差估计，包括全局多尺度空间的最优逼近性以及局部化导致的指数衰减性质；并通过数值实验验证了多尺度基函数的指数衰减特性；最后评论了 CEM-GMsFEM 在当前多个前沿方向的扩展和应用。本文旨在为读者提供一份完整的参考，以理解和实施这一方法。

2. 主要定理或主要结果#

本文综述了 CEM-GMsFEM 已有的主要理论结果，这些结果在适当假设下保证了方法的收敛性和稳健性。设 $\Lambda = \min_j \lambda_{j,k+1}$ 为所有粗子域上第 $k+1$ 个特征值的最小值，其中 $k$ 为每个子域所选取的局部特征函数个数。全局多尺度空间 $V_{H,\infty}$ 由算子 $G_\infty$ 的像构成，它精确满足正交分解 $V = V_{H,\infty} \oplus W$，其中 $W = V \cap \ker \pi$。利用这一分解，可得如下最优误差估计：若 $u$ 为原问题 (1) 的解，$u_{H,\infty}^{ms}$ 为相应的全局多尺度 Galerkin 逼近，则

$$\|u - u_{H,\infty}^{ms}\|_a \le \frac{1}{\sqrt{\Lambda}} \|f\|_{s^*},$$

其中 $\|\cdot\|_a$ 为能量范数，$\|\cdot\|_{s^*}$ 为对偶范数，且 $\|f\|_{s^*} \le H \frac{1}{\min \kappa} \|f\|_{L^2(\Omega)}$，表明误差关于粗网格尺寸 $H$ 至少是一阶收敛，且与对比度无关（当 $\Lambda$ 与对比度无关时）。这一结果与 Kolmogorov $n$-宽度理论相符，显示出空间 $V_{H,\infty}$ 的逼近最优性。

局部多尺度空间 $V_{H,l}$ 通过引入 $l$ 层过采样构造而成，对应的算子记为 $G_l$。误差分析的关键在于证明全局基函数的指数衰减性质以及局部与全局算子之差的指数衰减。具体地，对于任意 $v \in L^2(K_j)$，有引理 3.3：

$$\|G_{j,\infty}v\|_{a(\Omega\setminus K_{j,l})}^2 + \|\pi G_{j,\infty}v\|_{s(\Omega\setminus K_{j,l})}^2 \le \theta^l \big( \|G_{j,\infty}v\|_a^2 + \|\pi G_{j,\infty}v\|_s^2 \big),$$

其中 $\theta = c^*/(c^*+1) < 1$，而 $c^*(\Lambda)$ 由下式给出：

$$c^*(\Lambda) = \max_{x\in[0,\pi/2]} (\cos x + \sin x) \left( \frac{\cos x}{\sqrt{\Lambda}} + \sin x \right).$$

进一步，局部算子与全局算子的差满足引理 3.4：

$$\|(G_{j,\infty} - G_{j,l})v\|_a^2 + \|\pi (G_{j,\infty} - G_{j,l})v\|_s^2 \le c^\star \theta^{l-1} \big( \|G_{j,\infty}v\|_a^2 + \|\pi G_{j,\infty}v\|_s^2 \big),$$

其中 $c^\star(\Lambda) = \max_{x\in[0,\pi/2]} \big[ (\frac{1}{\sqrt{\Lambda}}+1)\cos x + \sin x \big]^2 + \big( \frac{\cos x}{\sqrt{\Lambda}} + \sin x \big)^2$。由此可组合得出局部多尺度逼近 $u_{H,l}^{ms}$ 的误差估计：

$$\|u - u_{H,l}^{ms}\|_a \le C \left(\frac{1}{\sqrt{\Lambda}} + \sqrt{c^\star}\, \theta^{\frac{l-1}{2}} \right) \|f\|_{s^*}.$$

上述估计仅依赖于粗网格正则性、过采样层数 $l$ 和特征值比 $\Lambda$，而不涉及 $\kappa$ 的对比度，从而保证了方法对高对比度系数的稳健性。数值模拟进一步验证了多尺度基函数的指数衰减特性，与理论结果一致。

3. 研究方法、关键技术和核心工具#

证明中的核心技术障碍在于：如何对一般高对比度系数构造具有全局连续性的局部基函数，并满足最优逼近性，同时避免系数的高低对比度影响估计常数。CEM-GMsFEM 的解决方案可概括为以下关键创新：

  1. 谱辅助空间与投影的逼近性质：在每个粗子域 $K_j$ 上，求解带有 Neumann 边界条件的特征值问题

    $$a_j(\Phi_{j,k}, v) = \lambda_{j,k} s_j(\Phi_{j,k}, v), \quad \forall v\in H^1(K_j),$$

    其中 $a_j(\Phi,v)=\int_{K_j} \kappa \nabla \Phi \cdot \nabla v$, $s_j(\Phi,v)=\int_{K_j} \tilde{\kappa} \Phi v$, 且权函数 $\tilde{\kappa}$ 选为 $\tilde{\kappa} = \kappa C_{\rm msh} H^{-2}$。这样的尺度使得特征值 $\lambda_{j,k}$ 无量纲，并且与对比度无关（若 $\kappa$ 与 $H$ 无关）。取前 $L$ 个特征函数张成局部辅助空间 $V_j^{\rm aux}$，定义投影 $\pi_j:L^2(K_j)\to V_j^{\rm aux}$，它满足两个关键估计：

    $$\|\pi_j u\|_{s_j} \le \|u\|_{s_j}, \qquad \|u - \pi_j u\|_{s_j} \le \lambda_{j,L+1}^{-1/2} \|u\|_{a_j}, \quad \forall u\in H^1(K_j).$$

    这为将解分解为“好”的部分（可被辅助空间捕捉）和“坏”的部分（能量控制 $L^2$ 加权范数）奠定了基础。

  2. 能量最小化构造与松弛公式：在每个 oversampled 域 $K_{j,l}$ 上，为每个特征函数 $\Phi_{j,k}$ 构造基函数 $\Psi_{j,k}$ 时，采用能量最小化：

    • 约束形式：求解 $\min \int_{K_{j,l}} \kappa |\nabla v|^2$，满足正交约束 $s(\pi v, \Phi_{j',k'}) = \delta_{jj'}\delta_{kk'}$，这导致鞍点系统。
    • 松弛形式：求解 $\min \int_{K_{j,l}} \kappa |\nabla v|^2 + s(\pi v - \Phi_{j,k}, \pi v - \Phi_{j,k})$，通过罚方法将约束融入目标函数，转化为标准正定系统，显著简化求解。松弛形式是理论分析的主要对象，但其误差同样可控制。

  3. 正交分解与最优性：全局多尺度空间 $V_{H,\infty}$ 由所有全局算子 $G_{j,\infty}$ 的像生成，通过分析证明其与 $W = V\cap \ker \pi$ 构成 $V$ 的直和分解。核心在于：对任一 $v\in W$，利用特征值不等式有 $\|v\|_s^2 = \sum_j \|v\|_{s_j}^2 \le \sum_j \lambda_{j,L+1}^{-1} \|v\|_{a_j}^2 \le \Lambda^{-1} \|v\|_a^2$，因此 $W$ 中函数的能量范数控制 $s$ 范数。进一步，由 Galerkin 正交性，误差 $e$ 必然落入 $W$，从而：

    $$\|e\|_a^2 = a(e,e) = (f,e) \le \|f\|_{s^*} \|e\|_s \le \frac{1}{\sqrt{\Lambda}} \|f\|_{s^*} \|e\|_a,$$

    立即得到定理 3.2。这一估计清晰展示了 $\Lambda$ 的作用：$\Lambda$ 越大（即取更多的局部特征函数），逼近误差越小。

  4. 指数衰减与局部化：引入 cut-off 函数 $\chi_j^{l,l'}$，满足 $\kappa|\nabla \chi|^2 \le \tilde{\kappa}$（得益于 $\tilde{\kappa}$ 的选取）。证明链如下：

    • 第一步（引理 3.3）：在 (4) 中取测试函数 $(1-\chi_{j}^{l-1,l}) G_{j,\infty}v$，将 $\Omega\setminus K_{j,l}$ 上的能量用 $K_{j,l}\setminus K_{j,l-1}$ 上的量表示，利用 $\chi$ 的性质和 Cauchy-Schwarz 不等式，结合 $W$ 空间中的范数控制，导出递推不等式： $$A_{l-1} \ge (1+1/c^*) A_{l},$$ 其中 $A_l = \|G_{j,\infty}v\|_{a(\Omega\setminus K_{j,l})}^2 + \|\pi G_{j,\infty}v\|_{s(\Omega\setminus K_{j,l})}^2$。由此迭代得 $A_l \le \theta^l A_0$，即指数衰减。
    • 第二步（引理 3.4）：将差 $z_j = G_{j,\infty}v - G_{j,l}v$ 分解为 $z_j = z_j' + z_j''$，其中 $z_j' = (1-\chi_j^{l-1,l}) G_{j,\infty}v$，$z_j''$ 属于 $V_{j,l}$。利用变分等式 $a(z_j, z_j'') + s(\pi z_j, \pi z_j'') = 0$ 和 $z_j'$ 的估计，结合第一步的结果，得到 $z_j$ 的误差界，同样呈现指数衰减。

  5. 常数优化：特别注意到在不等式的推导中，通过引入参数 $x$（代表范数比例）并取最大值，得到了与 $\Lambda$ 相关但形式上统一的最优常数 $c^*$ 和 $c^\star$，使得 $\theta$ 尽可能小。这一技巧保证了估计精确。

这些技术综合起来，使得 CEM-GMsFEM 能够在最小假设下（只需 $\kappa$ 满足椭圆性，网格正则性）获得与对比度无关的误差估计和指数衰减，为方法的实际应用提供了坚实的理论基础。

4. 与之前工作的比较#

CEM-GMsFEM 的提出和发展是建立在多尺度有限元领域的持续进展之上，与多种已有方法既有联系又有显著改进。下面从几个维度进行比较：

  1. 与 MsFEM 的比较：经典的 MsFEM 在粗网格单元上直接求解局部椭圆问题（通常施加 Dirichlet 或 Neumann 边界）来构造基函数，其精度依赖于系数与基函数边界的尺度分离。当存在强通道或高对比度时，边界条件可能引入严重误差，且没有系统性的误差控制 [36, 37, 66]。CEM-GMsFEM 通过过采样和约束能量最小化克服了边界影响：基函数在更大的子域上构造，并以全局协调的方式满足近似正交性，从而在理论上保证了指数衰减的局部化，即使没有尺度分离也成立。

  2. 与 GMsFEM 的比较：GMsFEM [28] 同样利用局部谱分解获得辅助空间，但通常直接使用这些特征函数（或其简单组合）作为多尺度基函数，或者通过特定的局部插值来形成全局基函数。这样的基函数可能不是最佳的，且缺乏类似 LOD 的严格误差分析框架。CEM-GMsFEM 对这些特征函数施加能量最小化，得到了满足全局连续性的最优逼近基函数，并建立了如同 LOD 的完整理论保证，同时保留了 GMsFEM 处理高对比度的优势。在实现上，GMsFEM 的需求可以通过 CEM-GMsFEM 的子模块直接实现。

  3. 与 LOD 的比较：LOD [46, 47] 依赖一个细致的拟插值算子 $\mathcal{I}$（如通过对节点值进行分片线性插值再修正）将解分解为 $u = \mathcal{I}u + (u-\mathcal{I}u)$，然后通过求解细尺度子问题获得校正项。拟插值算子的构造需要利用系数 $\kappa$ 的信息，且对于高对比度情形，可能不是对比度稳健的——实际上，标准的拟插值算子产生的逼近界可能依赖于对比度 [47]。相比之下，CEM-GMsFEM 用谱投影 $\pi$ 代替拟插值，而 $\pi$ 由局部特征值问题定义，其所满足的逼近估计（$\|u-\pi u\|_s \le \lambda_{L+1}^{-1/2}\|u\|_a$）自动与对比度无关。此外，LOD 需要求解鞍点问题或罚公式，而 CEM-GMsFEM 的松弛形式直接导向正定系统，实现更简单且避免 inf-sup 稳定性问题。

  4. 对比度稳健性：本文多处强调 CEM-GMsFEM 的对比度稳健性并非无代价——它依赖于特征值问题中权函数 $\tilde{\kappa}$ 与 $\kappa$ 成比例，从而特征函数能很好地分离高低传导区域。LOD 在最初的分析中并未显式探讨对比度，但通过选用特定的权函数，LOD 也可达到对比度稳健。从这个角度看，CEM-GMsFEM 提供了更系统的框架。文中还指出，若仅关心多尺度逼近而不考虑对比度，则可以使用齐次 Poisson 算子构造预条件，但此时迭代次数会随对比度增长而发散；CEM-GMsFEM 本质上构造了一个对比度稳健的粗空间，可以用作预条件或直接 Galerkin。

  5. 计算代价与灵活性：由于每个粗子域需要求解特征值问题和局部能量最小化问题，CEM-GMsFEM 的离线计算量显著高于传统方法，但这些计算是完全并行的。松弛公式为减轻计算提供了途径，尤其是当精细自由度可以无重叠分区时，可通过 Sherman-Morrison 公式将求解规模降至与特征函数总数成比例的小稠密系统。与 LOD 相比，CEM-GMsFEM 不要求构造显式的拟插值，对网格和系数分布的适应性更强。在非协调网格、非多项式有限元或有限体积法框架下的推广也较为自然，但相关研究尚处早期阶段。

  6. 与预条件技术的联系：近年来发展的一些对比度稳健的多水平预条件（如谱 AMG 方法）同样利用了局部谱空间构造粗空间 [68, 69]，其精神与 CEM-GMsFEM 异曲同工。然而，CEM-GMsFEM 提供了完整的 Galerkin 多尺度近似框架，而不仅是预条件中的粗空间校正，故可直接用于降阶建模或不确定性量化等任务。

总体而言，CEM-GMsFEM 成功融合了 GMsFEM 的谱降维、LOD 的局部化与最优逼近理论，以及能量最小化带来的实现灵活性，成为一类面向高对比度多尺度问题的有力工具。本综述通过系统梳理这些联系与创新，帮助读者理解为何 CEM-GMsFEM 能够达到目前的理论与实践效果。
