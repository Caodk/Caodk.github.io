1. 基于质量守恒混合虚拟元的多边形与切割网格变饱和流动#

Variably saturated flow on polygonal and cut meshes using a mass-conservative hybrid virtual element

作者: Francesco Salvatore Liguori

类别: math.NA

发布日期: 2026-11-05

arXiv ID: 2611.08276v1

链接: http://arxiv.org/abs/2611.08276v1

摘要翻译#

中文标题: 基于质量守恒混合虚拟元的多边形与切割网格变饱和流动

摘要翻译: 提出了一种混合虚拟元格式（HVEM），用于由 Richards 方程控制的变饱和土壤中的瞬态流动。节点水头是唯一的全局自由度，并在每个多边形单元中假定 Darcy 通量并将其凝聚。该通量将无散度部分与一个散度为线性的特定场相结合，后者吸收储水项和源项，从而每个单元的水量平衡在每个迭代步和任意时间步下恒等成立，并在收敛时整个区域的水量平衡成立。为保证无需稳定化参数即可满秩，无散度场采用按其旋转下的行为排序的调和多项式，从而给出通量参数数目的闭式规则；该规则在正多边形上推导，并在畸变多边形和带悬挂节点的单元上数值验证。在每个单元中针对 Kirchhoff 势写出 Darcy 定律，这消除了扩散项中的导水率，同时水头在材料界面处保持连续。导水率的 Kirchhoff 平均使静水平衡和重力排水在任何网格上都是精确的。储水项按节点集中，其权重由假定通量提供。所有单元算子都化为边界积分，因此非线性迭代只需节点值。该格式在闭式解、已发表基准以及均质与分层边坡上的降雨入渗问题上进行评估，其中独立解提供了进一步校验。在多头和局部加密网格上，水头以二阶收敛，在重力占优时亦然，并在每个测试中闭合水量收支。在分层边坡上，沿地表条带加密的切割网格以约 40% 的节点数达到细一倍的均匀网格的精度。其结构与用于弹塑性的 HVEM 共享，适用于边坡耦合分析。

2. 基于相容有限元的球面浅水方程二阶半隐式投影时间步进格式#

A Second-Order Semi-Implicit Projection Time-Stepping Scheme for the Shallow-Water Equations on the Sphere Using Compatible Finite Elements

作者: Karina Kowalczyk, Colin Cotter

类别: math.NA

发布日期: 2026-11-05

arXiv ID: 2611.08169v1

链接: http://arxiv.org/abs/2611.08169v1

摘要翻译#

中文标题: 基于相容有限元的球面浅水方程二阶半隐式投影时间步进格式

摘要翻译: 我们提出一种基于相容有限元离散的球面浅水方程的二阶半隐式时间步进格式。该格式将平流算子与波算子分裂，对平流部分采用 DG-upwind SSPRK3 方法，对波部分采用 $H(\text{div})$-协调的隐式离散，并通过杂交化高效求解。该格式采用三步对称分裂：一个显式半步、一个完整平流步，以及一个同时将速度重新投影回 $H(\text{div})$ 空间的隐式半步。这种对称性保证了全局二阶精度，并将稳定性限制仅局限于平流步的 CFL 条件。因此，可以通过对平流步进行子循环来将时间步长扩展到该限制之外，而无需额外的隐式求解。该方法在 Firedrake 中实现，并针对标准球面浅水基准测试集进行了验证，结果表明：使用二阶有限元时，在 Courant 数高达 1（采用两个平流子循环）的情况下结果稳定，具有二阶收敛性和良好的并行扩展性。

3. 渐近保持张量神经网络用于三维高场动理学方程及其在不确定性量化中的应用#

Asymptotic-Preserving Tensor Neural Networks for 3D High-Field Kinetic Equations with Applications to Uncertainty Quantification

作者: Shi Jin, Tian-ai Zhang

类别: math.NA, cs.LG

发布日期: 2026-11-05

arXiv ID: 2611.07364v1

链接: http://arxiv.org/abs/2611.07364v1

摘要翻译#

中文标题: 渐近保持张量神经网络用于三维高场动理学方程及其在不确定性量化中的应用

摘要翻译: 高场区域中的动理学方程描述由电场加速和碰撞弛豫主导的粒子输运。这些方程广泛用于等离子体和半导体器件模拟。典型模型包括 Vlasov–Poisson–Fokker–Planck (VPFP) 和 Boltzmann–Poisson 系统。其高维性和多尺度性质是精确高效数值求解的两大主要挑战。为应对这些挑战，我们提出一种渐近保持张量神经网络 (APTNN) 方法。具体而言，为降低高维计算成本和内存需求，我们采用 TNN 的 canonical polyadic (CP) 分解结构来近似其解。我们证明方程残差保持该分解形式，从而可通过一维积分组合来计算高维损失积分。由此计算和存储成本随维数从指数增长降为多项式增长。为提高高场极限下的预测精度，我们通过引入一阶矩方程增强基线 AP 损失。所添加的损失项直接约束极限通量闭合，以减小其在高场区域中的近似误差。增强后的 AP 损失仍可按维评估。数值结果表明，APTNN 在高场区域提高了预测精度，同时显著降低计算成本和内存使用。对于具有多个随机输入的 3D3V VPFP 问题，在单个 GPU 上训练耗时不到 30 分钟。
