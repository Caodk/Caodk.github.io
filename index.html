A Decoupled Low-Order Conforming Mixed Finite Element Method for a Three-Dimensional Fourth-Order Singularly Perturbed Problem

类别: math.NA

发布日期: 2026-06-10

arXiv ID: 2606.12176v1

摘要翻译#

中文标题: 一种三维四阶奇异摄动问题的解耦低阶协调混合有限元方法

摘要翻译: 本文针对三维空间中的四阶椭圆奇异摄动问题，提出了一种解耦的低阶协调有限元方法。借助广义Helmholtz分解，该问题被化为两个二阶椭圆问题以及一组满足无旋约束的广义奇异摄动Stokes型方程组。前者采用标准线性有限元离散。对于后者，我们使用MINI元，并证明在添加涉及Lagrange乘子的$L^2$项后，所得离散化关于摄动参数具有鲁棒性。我们进一步建立了关于摄动参数一致的阶为$h^{1/2}$的误差估计。数值实验被给出以支持该理论。

2. 完全解耦、线性且保结构的块中心有限差分方法用于交错非均匀网格上的Keller-Segel趋化系统#

Fully decoupled, linear and structure-preserving block-centered finite difference methods for the Keller-Segel chemotaxis system on staggered non-uniform grids

作者: Jie Xu, Hongfei Fu

类别: math.NA

发布日期: 2026-06-10

arXiv ID: 2606.12095v1

链接: http://arxiv.org/abs/2606.12095v1

摘要翻译#

中文标题: 完全解耦、线性且保结构的块中心有限差分方法用于交错非均匀网格上的Keller-Segel趋化系统

摘要翻译: 本文针对经典Keller-Segel趋化系统，在交错非均匀空间网格上提出了两种完全解耦、线性且保结构的块中心有限差分格式。这两种新格式在空间上均具有二阶精度；一种在时间上为一阶精度，另一种达到时间二阶精度。此外，我们证明了这些格式在离散层面上保持若干固有的物理定律：(i) 细胞密度和化学吸引剂浓度的正值性；(ii) 总细胞质量守恒；(iii) 一阶格式的离散能量耗散性质。特别地，时间一阶格式无条件保持正值性、质量守恒和能量耗散，而二阶格式在充分（但非必要）的时间步长条件下确保正值性。所提出的方法在指定的非均匀空间网格上能够更准确、高效地模拟趋化动力学，尤其是在快速爆破现象存在时。数值实验验证了理论结果，并说明了所提格式的准确性和可靠性。

摘要翻译: 我们提出并分析了一种用于耦合非牛顿Stokes-Darcy系统数值近似的多边形间断Galerkin方法，该系统模拟了非牛顿自由流流体与通过多孔介质的非牛顿流之间的相互作用。由于几何灵活性和任意阶精度，所提出的离散格式非常适合具有复杂几何形状的配置。我们提供了完整的先验分析，分别考虑了自由流和多孔介质区域的剪切依赖和速度依赖的非牛顿粘度模型。在广义inf-sup理论框架下建立了方法的适定性、稳定性和误差界。误差估计通过数值结果得到了确认。
